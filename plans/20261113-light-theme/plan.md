# Permanent light theme conversion

## Outcome and boundaries

Deliver Light Scientific Editorial across all four existing tabs, Gradio controls,
Plotly figures and Three.js. Always light, including dark OS preferences and explicit
Gradio dark requests. Preserve layout, typography, coordinates, numerical results,
model artifacts, inference, privacy boundaries and all established interactions.
No theme chooser, persistent preference, backend changes or new dependencies.

## Design brief

Register: Product, scientific music research studio.
Scene: Researchers exploring acoustic groups on desktop, tablet and phone in calm daylight.
Direction: Light Scientific Editorial; precise data and readable caveats lead.
Color: Restrained; off-white background, charcoal text, deep teal/violet identities.
Type: Existing system serif display + sans body + mono scientific labels.
Signature: Genuine acoustic PCA map; preserve its geometry and interactions.
Dials: variance 3, motion 2, density 6; retain existing dimensions and motion.

## Phases and acceptance

1. Audit shared tokens, embedded CSS/JS, Plotly and Three.js. Capture baseline at
   1440x900, 768x1024 and 375x812. Preserve unrelated working files.
2. Centralize light tokens and render every surface in light. No separate dark palette.
3. Verify real application screenshots of four tabs at all widths; dark preference,
   refresh, modes, selection, filter, camera, prediction, errors and fallbacks.
4. Run focused then full tests, Ruff, build and diff review. Document measured
   contrast, screenshot paths and limitations. Commit scoped changes; publish only
   through the existing authorized release route, without force push.
